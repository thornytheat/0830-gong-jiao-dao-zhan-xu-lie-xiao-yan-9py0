# 字段与业务定义

输入编码 UTF-8，允许 BOM。首行必须匹配样例列顺序。记录键和业务组保留原始字符串。`kind` 允许 stop, ping, dispatch。说明列 `note` 可以跨行，限制 200 字。

业务字段按 `station`、`ordinal`、`second`、`score`、`minimum` 排列。最终值单位见阶段结果。数字接受非负整数、全角数字和完整千分位。空串、短横线、N/A、NULL 与未知为缺值。无关字段用 0 占位。

候选点需属于班次站序、置信度 1–100，时点不能超过班次截止。路径时间与站序都严格递增，优先覆盖已登记站点，再比较置信度总分，最后按记录键稳定选取。允许缺站，但覆盖低于调度清单要求需复核。

人工确认到站不来自 CSV，由工作台在批次执行后补传，字段为业务组 `case`、站点 `station`（与来源同口径的整数站点编号）、到站时点 `second`（不超过班次截止）。确认点是该业务组路径必须命中的锚点：与同站同时的定位点合并计站，否则作为独立到站节点计入有效站次。确认点之间时间与站序必须严格递增，否则该组判 `CONFIRMATION_CONFLICT` 暂缓；撤回后按剩余确认点重新核算。

`incoming.csv` 包含四个业务组，第二组提供不同边界，第三组触发业务拒收，第四组需要核对。另含重复表头、冲突记录、重复回放与错误列数。`ready.csv` 含可以签发的两个组。
